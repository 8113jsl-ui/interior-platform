- A/B 비교 선택 후 키보드 오른쪽 방향키: A 51% / B 49%로 변경 확인
- PDF 미리보기 링크의 `?preview=1` 확인
- 모바일 390×844 프로젝트 화면 표시, 페이지 폭이 뷰포트를 넘지 않음
- 점검한 업무 화면 브라우저 콘솔 오류 없음
- 메인 클론 로딩·배경·레이아웃·모션 시각 확인 및 로컬 자산 누락 보완
