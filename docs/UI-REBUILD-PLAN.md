# Heron 업무 UI 재구성 계획

> 실행: subagent-driven-development로 독립 기능을 구현하고 실제 브라우저에서 통합 검증한다.

목표: 붙여넣은 브리핑의 PM·고객·현장 역할과 6개 업무 탭을 유지하면서 Heron 원본 CSS의 프레임·서체·그리드·모션을 업무 화면 전체에 적용한다.

기준: 사용자 첨부 pasted-text.txt가 기능 충돌 시 우선한다. SITE_DESIGN.md와 SITE_STRUCTURE.md는 분류와 구조의 참고 자료이다. 다른 저장소에 관한 Next.js/금색 UI 지시를 현재 프로젝트에 그대로 적용하지 않는다.

## 작업 및 경계

- [x] 1. 출처 분석: 원본 CSS의 폰트·색상·프레임·반응형 수치를 확인한다. 실제 레퍼런스와 현재 화면을 캡처해 비교한다.
- [x] 2. 공통 UI: reference-ui.css와 workspace-ui.js로 화면을 재구성하고 motion.js를 다시 작성한다. 헤더, 큰 도면 영역, 분할 제목, 셀 방식 목록, 상세 파일·기록 패널, 우측 편집 폼, 로그인에 같은 시스템을 적용한다. 장식은 데이터가 아닌 도면 모티프임을 명시한다.
- [x] 3. 기능 보완: 고객 홈의 표시 순서를 원본 참조 방식으로 저장한다. 자재 공간 필터, 사진 날짜 범위·업로더 필터, 일정 시작/종료 시간, 비교 이미지 접근 실패 구분을 구현한다. 공개·확정·초대 정책은 현재 서버 권한 경계를 유지한다.
- [x] 4. 화면 레지스트리: 역할·부모·뎁스·정규 경로를 문서/코드에서 추적하고 브리핑 완료표를 작성한다.
- [x] 5. 검증: 기존 권한/데이터 테스트와 새 동작 계약 테스트 총 57개, 1440px/390px 브라우저, 한국어/영어, 모달·탭·비교·저장 후 재조회. 최종 ZIP의 문법·압축 무결성과 비밀값/검증 DB 제외를 확인한다.

## 인터페이스

프로젝트 `homeSections`: `overview`, `recent`, `schedule`, `resources`의 순서 배열. 생략하면 기본 순서. 실제 자료는 기존 items/history를 조회하고 복제하지 않는다.
일정 `date`, `time`, `endDate`, `endTime`: Asia/Seoul의 달력 날짜/시각 문자열. 종료가 시작보다 앞서면 거절한다. 날짜 전용 일정도 지원한다.
자료 필터: 카테고리와 공간, 공정과 촬영 시작/종료일 및 업로더를 각각 독립 적용한다.

## 현재 판단

문서 간 충돌은 사용자가 100% 기준으로 지정한 브리핑을 우선한다. 구매 관리/운영자 콘솔/확정 코드는 이 UI 수정에서 추가하지 않는다. 다른 문서가 최종 우선순위라면 해당 정책을 별도 적용해야 한다.
운영 DB·배포 키는 받지 않았으므로 로컬 서버 검증과 배포 설정 제공까지 진행한다.
